# SENTINEL EYE

Global cyber threat detection and intelligence visualization platform with a real-time 3D CesiumJS globe, 14 intelligence tabs, and live tracking capabilities.

Part of the [Darknode](https://darknode.ai) cybersecurity education platform.

## Features

- Real-time 3D globe visualization using CesiumJS 1.124
- 14 intelligence tabs covering SIGINT, GEOINT, MASINT, ELINT, and more
- Live satellite and ISS tracking
- Nation-state threat profiles with APT group mapping
- Cyber event timeline with severity filtering
- ArcGIS imagery tiles integration
- Responsive design with full-width layout
